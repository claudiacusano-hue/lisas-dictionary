# LISAS Dictionary

Sito del dizionario LISAS, collegato al progetto di ricerca [LISAS-ICL](https://github.com/claudiacusano-hue/LISAS-ICL).

Funzioni previste:

- consultazione del dizionario;
- proposta di nuovi lemmi da parte dei visitatori;
- approvazione delle proposte da parte degli amministratori.

Stack previsto: GitHub Pages per il sito e Supabase per database e autenticazione.

Il dizionario esistente servirà per l'importazione iniziale. Le versioni usate negli esperimenti di LISAS-ICL saranno esportate e registrate esplicitamente, per mantenere riproducibili le valutazioni.

## Stato

Repository inizializzato. Implementazione in attesa delle specifiche complete.
